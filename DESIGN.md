# Design Notes

- Use Tailwind CSS and shadcn/ui as the default UI foundation.
- Reuse shared components for buttons, inputs, forms, cards, badges, dialogs,
  tabs, and layout primitives instead of restyling each screen independently.
- Keep spacing, border radius, borders, shadows, typography, and interaction
  states consistent across Caller Lab and Supervisor Dashboard.
- Prefer simple, readable, operational UI over decorative styling.
